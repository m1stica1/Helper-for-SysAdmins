# Helper for SysAdmins

Локальное приложение-помощник для администратора: инвентаризация сети, диагностика хостов, расчет подсетей, ARP-таблица и локальная системная сводка.

## Запуск

```powershell
python app.py
```

Откройте в браузере:

```text
http://127.0.0.1:8080
```

Если порт `8080` занят:

```powershell
python app.py --port 8090
```

## Разделы

- `Сканер`: поиск активных IP в CIDR, hostname, название устройства, MAC, задержка, открытые порты.
- `Инвентарь`: постоянные карточки устройств с типом, владельцем, локацией, статусом и заметками.
- `Журнал`: история запусков сканирования с сохраненными снимками результатов.
- `Диагностика`: ping, traceroute, DNS lookup, проверка TCP-портов.
- `Подсети`: сеть, broadcast, mask, wildcard, первый/последний usable host.
- `Система`: hostname, локальные IP, платформа, ARP-таблица.
- `Справочник`: быстрые команды и типовые порты.

## UI и темы

Интерфейс построен на общей системе токенов и поддерживает две темы:

- темная тема включается по умолчанию;
- светлая тема доступна через переключатель в верхней панели;
- выбор темы сохраняется в браузере через `localStorage`.

## Ограничения безопасности

- По умолчанию разрешено сканирование только приватных диапазонов RFC1918 и loopback.
- Максимум за один запуск: 1024 адреса.
- Инструменты запускают только заранее заданные команды, без произвольного shell-ввода.
- Используйте приложение только в сетях, где у вас есть разрешение на сканирование.

## Что сканируется

По умолчанию проверяются распространенные офисные TCP-порты:

`22, 80, 135, 139, 443, 445, 515, 631, 3389, 5000, 5985, 8000, 8080, 9100`

Порты можно изменить в интерфейсе.

## Профили сканирования

В `Сканере` можно сохранять наборы параметров в `scan_profiles.json`:

- название профиля;
- CIDR;
- TCP-порты;
- таймаут;
- количество потоков.

Профиль можно применить, обновить из текущих полей или удалить. По умолчанию создаются профили для офисной сети, принтеров и Windows/RDP/SMB.

## Названия устройств

Приложение пытается определить название устройства автоматически:

- ручная метка, закрепленная за IP или MAC;
- NetBIOS-имя через `nbtstat -A`;
- DNS hostname.

В таблице можно ввести понятное имя устройства, например `Принтер бухгалтерии`, и сохранить его кнопкой `✓` или клавишей Enter. Метки сохраняются локально в `device_names.json` и будут подставляться при следующих сканированиях.

## Инвентарь

После каждого сканирования найденные устройства автоматически попадают в `inventory.json`. В разделе `Инвентарь` можно вести рабочие карточки:

- тип устройства;
- ответственный;
- локация;
- статус;
- заметки;
- первое и последнее обнаружение;
- количество обнаружений.

Инвентарь можно фильтровать и экспортировать в JSON.

## Журнал сканирований

Каждый запуск сканера сохраняется в `scan_history.json`. Журнал хранит последние 50 запусков:

- CIDR и проверенные порты;
- дату и длительность;
- количество найденных устройств;
- суммарное число открытых портов;
- снимок найденных устройств.

Журнал можно фильтровать, просматривать детально, экспортировать в JSON и очищать без удаления инвентаря.

## Фильтрация

В `Сканере` можно фильтровать текущие результаты по:

- IP, hostname, MAC или названию;
- открытому TCP-порту;
- наличию открытых портов;
- наличию или отсутствию названия устройства.

В `Инвентаре` доступны фильтры по общему поиску, статусу, типу, владельцу и локации.
